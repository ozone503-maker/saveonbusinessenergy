Tell the agent

Directions are read first on the next scheduled run. The agent marks each one done with a note — or declined, with the reason, if it conflicts with the brief (for example, asking for outreach). A reprogram direction ("stop doing X, start doing Y") is picked up by the Maintenance Bot and takes effect on the next run, with no code deploy — see the result note it writes back.

Reprogram agent

Paste a large chunk of instructions — from you, Gavin, or another bot — and the Maintenance Bot rebuilds that agent inside the website. Up to 50,000 characters. A new version is created every time; history is never overwritten, and the raw paste is kept verbatim. The next run reads the new version — no code deploy. The brief's hard rules still bind it: a chunk that tries to override them (outreach without approval, invented contacts, Austin / San Antonio, "broker" wording, savings promises) is declined in part, and the reply says what was dropped and why.

Weekly megablast

Build the blast from a campaign, check the preview — recipient count, sample addresses, subject, body — then approve it. Approval arms it; it does NOT send it. Sending needs a second confirm, and only an approved blast can be sent. Unsubscribed addresses are excluded from every audience, and every email carries an unsubscribe link.
